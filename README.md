# Muhammad Anwar – Next.js Portfolio

A modern, responsive, and visually appealing personal portfolio website built with Next.js and React. This portfolio showcases my skills, technical expertise, projects, and professional experience as a web developer and software engineer.

The website features a clean user interface, smooth animations, interactive components, and responsive layouts to provide an engaging experience across desktop, tablet, and mobile devices.

## Features

* **Modern UI/UX:** Clean and professional design with an attractive layout.
* **Responsive Design:** Optimized for different screen sizes and devices.
* **Skills Showcase:** Highlights technical skills, tools, and technologies.
* **Projects Portfolio:** Displays personal and professional projects.
* **Professional Introduction:** Presents my background, experience, and expertise.
* **Smooth Animations:** Uses interactive elements and animations to enhance the user experience.
* **Reusable Components:** Structured components for maintainable and scalable development.
* **Optimized Performance:** Built with Next.js for efficient rendering and performance.

## Technologies Used

* Next.js
* React.js
* JavaScript / TypeScript
* Tailwind CSS
* HTML5 and CSS3
* React Fast Marquee
* Git and GitHub

## Purpose

This portfolio serves as my professional online presence, allowing recruiters, clients, and collaborators to explore my technical skills, completed projects, and development experience.

## Getting Started

Clone the repository, install the dependencies, and run the development server to explore or customize the project.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser to view the application.
